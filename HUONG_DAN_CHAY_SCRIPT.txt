═══════════════════════════════════════════════════════════════
   CÁCH CHẠY SCRIPT TEST - GIẢI QUYẾT LỖI HIỂN THỊ CODE
═══════════════════════════════════════════════════════════════

❌ VẤN ĐỀ:
   Khi chạy .\test-simple.ps1, PowerShell chỉ hiển thị code
   thay vì chạy script.

✅ GIẢI PHÁP:


═══════════════════════════════════════════════════════════════
   CÁCH 1: DÙNG FILE .BAT (DỄ NHẤT)
═══════════════════════════════════════════════════════════════

1. Double-click file: TEST_API.bat
   → File này sẽ tự động chạy script PowerShell

2. Hoặc click chuột phải → "Run as administrator"


═══════════════════════════════════════════════════════════════
   CÁCH 2: CHẠY VỚI LỆNH ĐẦY ĐỦ
═══════════════════════════════════════════════════════════════

Trong PowerShell, chạy:

powershell -ExecutionPolicy Bypass -File "G:\New folder\test-simple.ps1"

Hoặc nếu đã ở trong thư mục:

powershell -ExecutionPolicy Bypass -File ".\test-simple.ps1"


═══════════════════════════════════════════════════════════════
   CÁCH 3: SỬA EXECUTION POLICY (MỘT LẦN)
═══════════════════════════════════════════════════════════════

1. Mở PowerShell với quyền Administrator:
   → Click chuột phải vào PowerShell → "Run as administrator"

2. Chạy lệnh:
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

3. Chọn "Y" khi hỏi

4. Sau đó có thể chạy bình thường:
   .\test-simple.ps1


═══════════════════════════════════════════════════════════════
   CÁCH 4: COPY-PASTE TRỰC TIẾP (NẾU VẪN LỖI)
═══════════════════════════════════════════════════════════════

Mở PowerShell và copy-paste từng lệnh sau:

───────────────────────────────────────────────────────────────
Test 1:
───────────────────────────────────────────────────────────────
$body1 = @{
    service_name = "auth-service"
    severity = "error"
    log_message = "Failed to authenticate user: Invalid token"
    metadata = @{
        user_id = "12345"
        ip_address = "192.168.1.1"
    }
} | ConvertTo-Json -Depth 10

Invoke-RestMethod -Uri "http://localhost:3001/log/ingest" -Method Post -Body $body1 -ContentType "application/json"

───────────────────────────────────────────────────────────────
Test 2:
───────────────────────────────────────────────────────────────
$body2 = @{
    service_name = "database-service"
    severity = "critical"
    log_message = "Database connection timeout after 30 seconds"
    metadata = @{
        db_host = "db.example.com"
        retry_count = 3
    }
} | ConvertTo-Json -Depth 10

Invoke-RestMethod -Uri "http://localhost:3001/log/ingest" -Method Post -Body $body2 -ContentType "application/json"

───────────────────────────────────────────────────────────────
Test 3:
───────────────────────────────────────────────────────────────
$body3 = @{
    service_name = "api-gateway"

    }
} | ConvertTo-Json -Depth 10

Invoke-RestMethod -Uri "http://localhost:3001/log/ingest" -Method Post -Body $body3 -ContentType "application/json"
