   CÁCH CHẠY TEST - ĐƠN GIẢN NHẤT
═══════════════════════════════════════════════════════════════

❌ BẠN ĐANG Ở CMD (Command Prompt) - KHÔNG CHẠY ĐƯỢC!

✅ CÁCH ĐƠN GIẢN NHẤT:


═══════════════════════════════════════════════════════════════
   CÁCH 1: DOUBLE-CLICK FILE .BAT (DỄ NHẤT!)
═══════════════════════════════════════════════════════════════

1. Vào thư mục: G:\New folder
2. Tìm file: TEST_API.bat
3. Double-click (click đúp) vào file đó
4. Xem kết quả!

→ ĐÓ LÀ TẤT CẢ! KHÔNG CẦN GÕ LỆNH GÌ CẢ!


═══════════════════════════════════════════════════════════════
   CÁCH 2: MỞ POWERSHELL ĐÚNG CÁCH
═══════════════════════════════════════════════════════════════

Bước 1: Mở PowerShell
   → Nhấn phím: Windows + R
   → Gõ: powershell
   → Nhấn Enter

Bước 2: Di chuyển đến thư mục
   → Gõ: cd "G:\New folder"
   → Nhấn Enter

Bước 3: Chạy test
   → Gõ: .\test-simple.ps1
   → Nhấn Enter


═══════════════════════════════════════════════════════════════
   CÁCH 3: CHẠY TỪ CMD (NẾU KHÔNG MỞ ĐƯỢC POWERSHELL)
═══════════════════════════════════════════════════════════════

Trong CMD hiện tại, gõ:

powershell -ExecutionPolicy Bypass -File "test-simple.ps1"

Nhấn Enter


═══════════════════════════════════════════════════════════════
   PHÂN BIỆT CMD VÀ POWERSHELL
═══════════════════════════════════════════════════════════════

CMD (Command Prompt):
   → Prompt: C:\Users\...>
   → KHÔNG chạy được PowerShell script
   → Chỉ chạy được file .bat

PowerShell:
   → Prompt: PS C:\Users\...>
   → Có chữ "PS" ở đầu
   → Chạy được PowerShell script (.ps1)

   TÓM TẮT
═══════════════════════════════════════════════════════════════

→ KHÔNG CẦN GÕ LỆNH GÌ CẢ!
