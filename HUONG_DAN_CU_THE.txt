📌 BƯỚC 1: GIỮ SERVER ĐANG CHẠY
───────────────────────────────────────────────────────────────
   ✓ Cửa sổ PowerShell hiện tại đang chạy "npm run dev"
   ✓ ĐỪNG ĐÓNG cửa sổ này
   ✓ Để nó chạy tiếp


📌 BƯỚC 2: MỞ POWERSHELL MỚI
───────────────────────────────────────────────────────────────
   Cách 1: Nhấn Windows + R → gõ "powershell" → Enter
   
   Cách 2: Click Start Menu → tìm "PowerShell" → mở
   
   Cách 3: Click chuột phải vào Start → "Windows PowerShell"


📌 BƯỚC 3: DI CHUYỂN ĐẾN THỰ MỤC PROJECT
───────────────────────────────────────────────────────────────
   Trong PowerShell mới, gõ:
   
   cd "G:\New folder"
   
   Nhấn Enter
   
   (Bạn sẽ thấy: PS G:\New folder>)


📌 BƯỚC 4: CHẠY TEST
───────────────────────────────────────────────────────────────
   Cách 1: Dùng file .bat (Dễ nhất)
   → Double-click file: CHAY_TEST.bat
   
   Cách 2: Chạy script PowerShell
   → Gõ: .\test-simple.ps1
   → Nhấn Enter
   
   Cách 3: Test thủ công (nếu script không chạy)
   → Copy và paste từng lệnh dưới đây:

Test 1: Authentication Error
───────────────────────────────────────────────────────────────
$body1 = @{
    service_name = "auth-service"
    severity = "error"
    log_message = "Failed to authenticate user: Invalid token"
    metadata = @{
        user_id = "12345"
        ip_address = "192.168.1.1"
    }
} | ConvertTo-Json -Depth 10

Invoke-RestMethod -Uri "http://localhost:3001/log/ingest" -Method Post -Body $body1 -ContentType "application/json"


Test 2: Database Error

═══════════════════════════════════════════════════════════════
   NẾU GẶP LỖI
═══════════════════════════════════════════════════════════════

❌ Lỗi: "Execution Policy"
   → Chạy lệnh này trước:
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   → Chọn "Y" khi hỏi

❌ Lỗi: "Cannot connect"
   → Kiểm tra server đang chạy chưa (cửa sổ npm run dev)
   → Kiểm tra port 3001 (không phải 3000)

❌ Lỗi: "File not found"
   → Đảm bảo đang ở đúng thư mục: G:\New folder
   → Chạy: cd "G:\New folder"
